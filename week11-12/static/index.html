📚 API Design Patterns Guide

CRUD Pattern

Tương tác tài nguyên trực tiếp: POST /articles, GET /articles/<id>, PUT, DELETE.

Query Pattern

Lọc và tìm kiếm thông qua query parameters: q, status, page, limit.

HATEOAS Pattern

Response trả về các siêu liên kết (links) giúp client biết các endpoint hành động có sẵn tiếp theo mà không cần xem tài liệu API.

Webhook Security & Idempotency

Mỗi Subscriber có Secret Key để kiểm chứng tính xác thực (chữ ký gửi kèm header X-Webhook-Signature). Receiver lưu trữ X-Webhook-Id để phát hiện và bỏ qua các bản tin bị trùng lặp.
